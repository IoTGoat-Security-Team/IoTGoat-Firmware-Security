# ARM 어셈블리 주요 명령어(x/i $pc, stepi, info registers, x/3wx) 확인 요약

- PUSH : r4~r10, lr (8개 레지스터, 32바이트) 스택 저장
- SUB  : sub sp, sp, #48 -> sp 변화: 0x407fff48 -> 0x407fff18 (지역 공간 48바이트 확보)
- LDM  : r3가 가리키는 메모리에서 3개 값 일괄 로드 -> r0, r1, r2
- ADD  : add r6, sp, #4 -> r6 = 0x407fff1c (sp 유지)
- MOV  : r5 = 2
- STM  : LDM으로 읽은 3개 값을 r6 스택 공간에 연속 저장 (BusyBox 실행 인수 배열)
